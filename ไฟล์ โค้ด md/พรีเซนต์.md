## Slide 3 — ทฤษฎี: Image Segmentation

**Layout: ซ้าย = เนื้อหา + สมการ | ขวา = รูปตัวอย่าง**

### ซ้าย

**Image Segmentation คืออะไร?**
แบ่งภาพออกเป็น Region ที่มีคุณสมบัติเหมือนกัน เพื่อแยก Object ออกจาก Background

**Global Thresholding (Otsu)** — ใช้ใน TC2, TC3, TC4, TC5:

$$T^* = \arg\max_T \sigma_B^2(T)$$

หา $T$ ที่ทำให้ Between-class Variance สูงสุด

**Iterative Thresholding** — ใช้ใน TC6, TC7:

$$T_{n+1} = \frac{\mu_1(T_n) + \mu_2(T_n)}{2}$$

**Morphological Top-Hat (Local Thresholding)** — ใช้ใน TC7:

$$\hat{f} = f - (f \circ b)$$

ลบ Background ไม่สม่ำเสมอออกโดยใช้ Morphological Opening $f \circ b$

**Region-Based Segmentation:**
กรอง Region ด้วย Predicate $P(R_i)$ เช่น Area, Height (`bwareaopen`, `filter_regions`)

**Watershed + Distance Transform** — ใช้ใน TC7:
แยกตัวอักษรที่ติดกันด้วย `bwdist` → `imhmin` (ลด Over-segmentation) → `watershed`

### ขวา

รูปตัวอย่าง 3 ภาพเรียงกัน: Original → Grayscale → Binary Mask

## Slide 4 — ทฤษฎี: Edge Detection & Hough Transform

**Layout: ซ้าย = เนื้อหา | ขวา = รูปตัวอย่าง**

### ซ้าย

**Canny Edge Detection:**
Gaussian Blur → Gradient Magnitude → Non-Maximum Suppression → Double Threshold Hysteresis
→ ได้ขอบที่คม ทนต่อ Noise

**Hough Transform:**

$$\rho = x\cos\theta + y\sin\theta$$

แปลงพิกัด $(x, y)$ ใน Image Space → $(\rho, \theta)$ ใน Hough Space
ใช้ตรวจจับเส้นตรงเพื่อหา **Skew Angle** ของข้อความ
(`hough` RhoResolution 0.5 → `houghpeaks` 10 จุด → `houghlines` FillGap 10, MinLength 30)

**Deskewing:**
มุมเอียง $\alpha$ = ค่ามัธยฐานของมุมเส้นที่เกือบแนวนอน แล้วหมุนด้วย `imrotate` เมื่อ $|\alpha| > 0.3°$
ใช้ใน TC6 (Arturo's) และ TC7 (OPEN)

### ขวา

3 ภาพ: Canny Edge → Hough Space + Peaks → Hough Lines
(ได้จากการตั้ง `DEBUG = true` ใน test_case_6.m / test_case_7.m)

## Slide 5 — ทฤษฎี: OCR (Tesseract Engine)

**Layout: ซ้าย = Pipeline + เหตุผล | ขวา = Block Diagram**

### ซ้าย

**OCR คืออะไร:** แปลงภาพตัวอักษร → ข้อความดิจิทัล

**Tesseract Pipeline:**
Binarize → Layout Analysis → Feature Extraction → Language Model → Word + Confidence Output

**Word Confidence:** ค่าความเชื่อมั่นเฉลี่ยของตัวอักษรในคำ (ช่วง 0–1)

**Recognition Rate:** เปรียบเทียบคำที่อ่านได้กับ Ground Truth (เลือก GT ที่ตรงที่สุด)

- TC1–TC5 (เทียบตัวอักษรตามตำแหน่ง):

$$\text{Rate} = \frac{\#\{i : \text{rec}_i = \text{gt}_i\}}{\max(|\text{gt}|, |\text{rec}|)} \times 100$$

- TC6–TC7 (Levenshtein, ไม่สนตัวพิมพ์เล็ก/ใหญ่; ถ้าตัดเครื่องหมายแล้วตรงกัน = 100%):

$$\text{Rate} = \left(1 - \frac{\text{lev}(\text{rec}, \text{gt})}{\max(|\text{gt}|, |\text{rec}|)}\right) \times 100$$

> ค่าเฉลี่ยในตารางคิดจาก "คำที่ OCR อ่านได้" เท่านั้น (ไม่ได้หารด้วยจำนวนคำใน GT)

| ปัจจัย | ผลกระทบ |
|:---|:---|
| ตัวอักษรใหญ่เกินไป | OCR อ่านผิด → ย่อภาพ (TC4 ×0.3, TC5 ×0.5, TC6 Arturo's ×0.3–0.7) |
| ตัวอักษรเล็กเกินไป | รายละเอียดไม่พอ → ขยายภาพ (TC2 ×2, TC6 COAL OVEN ×1.5, TC7 BEST ×1.5) |
| ชิดขอบภาพ | ตีความเป็นเส้นกรอบ → ต้อง Padding |
| ฟอนต์ลายมือ / ตัวเอียง | Confidence ต่ำ |
| Noise มาก | Confidence ต่ำ |

### ขวา

Block Diagram: Image → Preprocess → OCR Engine → Word + Confidence

## Slide 19 — TC4: Blue Channel Difference (สมการ)

**Layout: ซ้าย = อธิบาย | ขวา = ตัวอย่างค่า + รูป**

### ซ้าย

$$f_{blue} = B - \frac{R + G}{2}$$

**แนวคิด:** คำนวณ "ความน้ำเงินสุทธิ" ของแต่ละ pixel แล้ว Normalize เป็นช่วง [0, 1] ด้วย `mat2gray` ก่อน Threshold

- สีน้ำเงิน: $B$ สูง, $R+G$ ต่ำ → **ค่าเป็นบวกสูง** → ตัวอักษร
- สีเทา/ขาว: $B \approx R \approx G$ → **ค่าใกล้ศูนย์** → พื้นหลัง
- สีแดง/เขียว: $B$ ต่ำ → **ค่าเป็นลบ** → พื้นหลัง

**ทำไมไม่ใช้แค่ B channel ตรงๆ?**

> สีขาว/เทามีค่า $B$ สูงเหมือนกัน → การหัก $\frac{R+G}{2}$ ออกจะเหลือเฉพาะ "น้ำเงินสุทธิ" จริงๆ

### ขวา

| สี | R | G | B | $f_{blue}$ | |
|:---:|:---:|:---:|:---:|:---:|:---:|
| น้ำเงิน | 20 | 30 | 180 | **+155** | ✅ ตัวอักษร |
| เทา (ผนัง) | 130 | 130 | 130 | **0** | ❌ พื้นหลัง |
| ขาว | 240 | 240 | 240 | **0** | ❌ พื้นหลัง |
| แดง | 200 | 20 | 20 | **-90** | ❌ พื้นหลัง |

## Slide 28 — TC6: Yellowness Feature (สมการ)

**Layout: ซ้าย = อธิบาย | ขวา = ตัวอย่างค่า + รูป**

### ซ้าย

$$f_{yellow} = \min(R, G) - B$$

ตามด้วย Gaussian smoothing ($\sigma = 0.8$) และตัดค่าให้อยู่ในช่วง [0, 255]

**แนวคิด:** สีเหลือง = $R$ สูง + $G$ สูง + $B$ ต่ำ

- $\min(R, G)$: ต้องการให้ **ทั้ง R และ G สูงพร้อมกัน**
- ลบ $B$: กรองสีที่มี Blue component สูง (เช่น ขาว, ฟ้า) ออก
- สีแดง (พื้นหลัง Arturo's): $G$ ต่ำ → $\min(R,G)$ ต่ำ → **กรองทิ้ง**
- สีดำ (พื้นหลัง COAL OVEN): ทุกค่าต่ำ → **กรองทิ้ง**

**ทำไมใช้ $\min(R,G)$ ไม่ใช้ $\frac{R+G}{2}$?**

> `min` เข้มงวดกว่า: หากค่าใดค่าหนึ่งต่ำ (เช่น สีส้มที่ G ต่ำ) จะถูกกรองทิ้ง

### ขวา

|:---:|:---:|:---:|:---:|:---:|:---:|

| แดง (พื้น) | 180 | 20 | 20 | **0** | ❌ พื้นหลัง |
| ดำ (พื้น) | 10 | 10 | 10 | **0** | ❌ พื้นหลัง |

## Slide 29 — TC6: Iterative Thresholding + Parameter Sweep (สมการ)

**Layout: ซ้าย = อธิบาย | ขวา = Diagram + รูป**

### ซ้าย

$$T_{n+1} = \frac{\mu_1(T_n) + \mu_2(T_n)}{2}$$

**ขั้นตอนการคำนวณ:**

| Step | การคำนวณ |
|:---|:---|
| เริ่มต้น | $T_0 = \frac{f_{max} + f_{min}}{2}$ |
| แบ่ง 2 กลุ่ม | $G_1$: intensity $\geq T_n$ (สว่าง), $G_2$: intensity $< T_n$ (มืด) |
| คำนวณ mean | $\mu_1 = \text{mean}(G_1)$, $\mu_2 = \text{mean}(G_2)$ |
| อัปเดต T | $T_{n+1} = \frac{\mu_1 + \mu_2}{2}$ |
| หยุดเมื่อ | $\|T_{n+1} - T_n\| < 0.5$ (สูงสุด 100 รอบ) |

**ปรับ Threshold ด้วยตัวคูณ k:** ใช้ $g = f_{yellow} \geq k \cdot T$ แล้วลองหลายชุดพารามิเตอร์ เลือกชุดที่ให้

$$\text{score} = \sum (\text{Confidence} \times \text{จำนวนตัวอักษร})$$

สูงสุด

| พารามิเตอร์ | Arturo's | COAL OVEN |
|:---|:---:|:---:|
| k | 1.1, 1.2, 1.3, 1.5, 1.8 | 0.7 – 1.2 |
| Scale | 0.3, 0.4, 0.5, 0.7 (ย่อ) | 1.5 (ขยาย) |
| แก้ตัวเอียง (Shear) | 0°, 10°, 20° | – |
| Deskew (Hough) | ✅ | – |
| CharacterSet | A–Z, a–z, ' | A–Z |

### ขวา

Diagram: Feature → Iterative $T$ → $k \cdot T$ → Mask → OCR → Score → เลือกชุดที่ดีที่สุด

ค่า $T_0$ และ $k$ ที่ถูกเลือกจริง: ดูจาก `info1.T0`, `info1.k`, `info2.T0`, `info2.k` หลังรันโค้ด

## Slide 35 — TC7: Polar-to-Cartesian Unwrapping (สมการ)

**Layout: ซ้าย = อธิบาย | ขวา = Diagram + รูปจริง**

### ซ้าย

$$x = c_x + r \cdot \cos(\theta)$$
$$y = c_y - r \cdot \sin(\theta)$$

**พารามิเตอร์ (พิกัดในภาพป้ายที่ crop แล้ว):**

| ตัวแปร | ความหมาย | ค่าจริง |
|:---:|:---|:---:|
| $(c_x, c_y)$ | จุดศูนย์กลางป้ายวงกลม | (143, 245) |
| $r \in [r_{in}, r_{out}]$ | ความหนาของวงแหวนข้อความ | [88, 135] |
| $\theta$ (WORLD'S) | ช่วงมุมข้อความบน (ซ้าย → ขวา ตามเข็มนาฬิกา) | 172°–188° → 10° (ลองหลายมุมเริ่ม เลือกที่ Confidence สูงสุด) |

**ขั้นตอน:**
1. สร้าง Grid ของ $(r, \theta)$

4. ได้ภาพ Strip แนวนอนที่ข้อความโค้งถูกคลี่แล้ว (WORLD'S: แถวบน = $r_{out}$, DONUTS: แถวบน = $r_{in}$ เพื่อให้ตัวอักษรไม่กลับหัว)
